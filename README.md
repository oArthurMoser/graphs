# Grafos — UNIVALI

Este repositório contém os trabalhos práticos da disciplina de Teoria dos Grafos:

- **[`m1/`](file:///Users/arthurmoser/Documents/Codes/univali/graphs/m1)**:
  - **Parte 1**: Estruturas de dados de Grafo (Matriz e Lista de Adjacência), operações básicas de manipulação.
  - **Parte 2**: Leitura de arquivos de grafos, Busca em Largura (BFS), Busca em Profundidade (DFS) e Algoritmo de Dijkstra.
- **[`m2/`](file:///Users/arthurmoser/Documents/Codes/univali/graphs/m2)**:
  - **Parte 1 (Coloração de Grafos)**: Força Bruta, Welsh & Powell, DSATUR e Heurística Sem Critério de Ordem (Ordem Arbitrária).
  - **Parte 2 (Árvore Geradora Mínima - AGM)**: Algoritmo de Prim e Algoritmo de Kruskal (Union-Find).

---

## Comandos Rápidos

```bash
# Compilar ambos os projetos (M1 e M2)
make all

# Executar a M1
make run-m1

# Executar a M2
make run-m2

# Limpeza
make clean
```
